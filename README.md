# Estimand-Protocol Mapping Tool

臨床試験のEstimandを手がかりとして、関連するProtocol／SAPの規定と、観測・確認すべき情報の候補を段階的に整理する研究用プロトタイプです。

本ツールは、**Estimandに対応する推定結果を意図した意味で解釈するために重要となり得る規定**を探索し、専門家によるレビュー、リスク評価、議論のたたき台を作ることを目的としています。

## 本ツールが行うこと

```text
Estimand・中間事象（ICE）
  ↓
Protocol／SAPの関連規定
  ↓
重要規定の候補
  ↓
観測・確認すべき情報の候補
  ↓
CTQ・リスク候補
```

解析は一括ではなく、以下の段階に分けて実行します。

1. Estimand、ICE、Strategyおよび対象文書の入力
2. 関連規定の抽出
3. 観測・確認すべき情報の特定
4. 必要に応じたCTQ・リスク候補の整理

## 本ツールが決定しないこと

本ツールは、以下を自動的に決定しません。

- 中央モニタリング／サイトモニタリングの選択
- SDV・SDRの要否
- 確認担当者、頻度、閾値
- KRIへの採用
- 全例確認／サンプリング
- リスク低減策
- 治験実施計画、統計解析計画、医学的・規制上の判断

これらは、出力された候補を基に、後続する多職種のリスク評価と専門家の判断によって検討することを想定しています。

## Estimand入力

主要な入力項目は以下です。

- 関心のある治療条件
- 対象集団
- 個人レベルの変数
- 中間事象（ICE）とStrategy
- 集団レベルの要約（任意・参考情報）

集団レベルの要約は主要なマッピング軸には使用せず、SAPとの整合性確認などの参考情報として扱います。

## ICEとStrategy

ICEは任意の数を表形式で追加・削除できます。同じICEでも、評価項目やStrategyが異なる場合は別の行として登録できます。

選択可能なStrategy：

- Treatment policy
- Hypothetical
- Composite variable
- While on treatment
- Principal stratum
- 未決定
- その他・複合的な取扱い

解析では、以下を区別して整理します。

1. ICEの発生を特定するための情報
2. Strategy適用の前提となる情報
3. Strategyに対応する解析に必要な情報
4. それらの情報を得るために関係する実施上の規定

Strategyは中間事象を踏まえた治療効果の定義上の取扱いであり、試験実施上の指示そのものとは区別して扱います。

## 対象文書

- Protocol PDF：必須
- SAP PDF：任意

ProtocolとSAPは別文書として扱い、文書名、章・項番号、ページおよび原文引用を保持するようAIへ指示します。

SAPに記載された解析上の取扱いから、施設や担当者の実施要件を自動的に生成しないよう制約しています。

## 観測・確認すべき情報

「情報」はEDCデータに限定しません。以下のような情報も候補になり得ます。

- EDCデータ
- 中央検査・中央判定情報
- 画像、検体、薬剤管理記録
- システムログ
- 検査・評価・手順の実施記録
- 施設原資料
- 設備、環境、運用状態

文書に直接記載された内容と、規定から論理的に導いた候補を区別して出力するよう設計しています。

## AI接続

- Google Gemini API
- LM StudioなどのOpenAI互換ローカルAPI

ローカルAPIの既定エンドポイント：

```text
http://localhost:1234/v1/chat/completions
```

## ローカルでの実行

```bash
git clone https://github.com/chan-kuwa/estimand.git
cd estimand
pip install -r requirements.txt
streamlit run ass.py
```

Gemini APIキーをStreamlit Secretsで設定する場合：

```toml
# .streamlit/secrets.toml
GOOGLE_API_KEY = "your-api-key"
```

## CTTI参照データ

実行環境に `000111598.xlsx` がある場合、CTQ・リスク候補の整理時にCTTI参照情報を利用します。「日本語訳」シートがある場合は同シートを優先します。

参照ファイルがなくても、関連規定と観測情報の解析は実行できます。

## 重要な注意事項

### 研究用プロトタイプ

本ツールは概念検証段階です。抽出・推論の妥当性、再現性、完全性および実務上の有用性は確立されていません。

### 原文確認

生成AIは、誤った記述、原文にない推論、引用箇所の取り違えを含む可能性があります。出力をそのまま公式記録や意思決定に使用せず、必ず原文と照合し、専門家が確認してください。

### 機密情報

外部APIを使用する場合、文書のテキストが外部サービスへ送信されます。所属組織の規程、契約、情報セキュリティ要件を確認し、未公開情報、機密情報、個人情報を許可なく入力しないでください。

## 開発状況

現在は、学会発表に向けて段階的に改修しています。今後の主な検討事項：

- 抽出結果の正確性と再現性
- ProtocolとSAPの一致・不一致表示の改善
- 専門家による内容妥当性評価
- 観測情報候補から多職種リスク評価への受け渡し
- 実際の試験運営における有用性
